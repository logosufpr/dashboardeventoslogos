# Política de Segurança

Obrigado por contribuir para a segurança do Dashboard de Eventos LOGOS.

A segurança dos dados e da disponibilidade do sistema é uma prioridade. Caso você identifique uma vulnerabilidade, pedimos que a reporte de forma responsável para que possamos analisá-la e corrigi-la antes de qualquer divulgação pública.

---

## Versões Suportadas

Atualmente, apenas a versão mais recente do Dashboard de Eventos LOGOS recebe correções de segurança e manutenção.

| Versão | Suporte |
| ------- | :------: |
| Atual (main) | ✅ |
| Versões anteriores | ❌ |

---

## Como reportar uma vulnerabilidade

Caso identifique uma possível vulnerabilidade, entre em contato com a equipe responsável pelo projeto.

Ao enviar um relatório, inclua, sempre que possível:

- Descrição da vulnerabilidade;
- Passos para reproduzir o problema;
- Impacto esperado;
- Evidências (prints ou vídeos, quando aplicável);
- Sugestões de correção (opcional).

---

## Processo de tratamento

Após o recebimento do relatório:

1. Confirmaremos o recebimento da comunicação.
2. Avaliaremos a vulnerabilidade.
3. Caso confirmada, iniciaremos o processo de correção.
4. Após a implementação da correção, o autor do relatório será informado.

Pedimos que vulnerabilidades não sejam divulgadas publicamente até que uma correção esteja disponível.

---

## Escopo

Esta política aplica-se aos componentes do Dashboard de Eventos LOGOS, incluindo:

- Interface Web;
- Sistema de autenticação;
- Banco de dados Firebase;
- Gerenciamento de usuários;
- Gerenciamento de eventos;
- Funcionalidades administrativas.

---

## Tecnologias utilizadas

O projeto utiliza, entre outras tecnologias:

- HTML5
- CSS3
- JavaScript (ES6+)
- Firebase Authentication
- Cloud Firestore
- GitHub Pages

---

## Boas práticas de segurança

O projeto busca seguir boas práticas, incluindo:

- Controle de acesso por perfil de usuário;
- Autenticação por e-mail e senha;
- Armazenamento de dados em ambiente seguro (Firebase);
- Proteção das regras de acesso do Firestore;
- Atualização contínua das dependências utilizadas.

---

## Contato

Para dúvidas ou comunicações relacionadas à segurança, entre em contato com a equipe responsável pelo projeto por meio dos canais institucionais da LOGOS/UFPR ou pelo mantenedor do repositório.
